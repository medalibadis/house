# تطبيق دعوة زفاف فاخرة وتفاعلية | ابراهيم حسام الدين
### Luxury Interactive Arabic Wedding Invitation Web Application

تطبيق ويب فاخر مصمم وفق منهجية الهاتف أولاً (`Mobile-First`) ثنائي المراحل:
**المرحلة 1: شاشة المظروف الملكي التفاعلي (Envelope Cover Landing)**
**المرحلة 2: بطاقة الدعوة الكاملة التفاعلية القابلة للتمرير (Interactive Scrollable Invitation)**

---

## 🎨 الهوية البصرية والتصميم (Visual Design & Aesthetic)
- **لوحة الألوان الملكية:**
  - خلفية ورقية عاجية دافئة ذات ملمس فاخر: `#FAF7F5`
  - لون العنابي العميق / المارسالا: `#7A1C33`
  - لمسات ذهبية عتيقة: `#B89758` / `#D4AF37`
  - نصوص فحمية دافئة: `#333333`
- **التأطير النباتي الفاخر (Botanical Floral Framing):**
  - رسومات مائية دقيقة ومتجهة عالية الدقة (SVG) لورود المارسالا المخملية، زهور الفاوانيا الوردية، وأوراق الكينا (Eucalyptus) وأغصان الزيتون المطرزة بلمسات الذهب.
  - إطار متوج في الزاوية العلوية، لمسات جانبية، وحافة نباتية مورقة تمتد على طول الجزء السفلي للشاشة.
- **الخطوط العربية (Typography):**
  - خطوط كلاسيكية أصيلة للعناوين والأسماء: **Amiri** و **Aref Ruqaa**
  - خطوط واضحة وعصرية لنصوص الدعوة والأرقام: **Cairo** و **Tajawal**

## 💌 المرحلة 1: شاشة المظروف الملكي التفاعلي (Interactive Envelope Cover)
1. **شعار المونوغرام الملكي:** دائرة مذهبة وعنابية تحمل حرفي العروسين المتقاطعين **("إ ح")**.
2. **العنوان العلوي:** عبارة *"دَعْوَةُ زَفَاف"* بخط كلاسيكي متباعد، يليها اسم العريس **"ابراهيم حسام الدين"** بالخط العنابي الكبير.
3. **المظروف ثلاثي الأبعاد:** مظروف بلون العنابي المخملي `#7A1C33` مع ختم شمعي معدني مذهب ثلاثي الأبعاد وعبارة *"اضغط لفتح الدعوة"*.
4. **التفاعل:** عند الضغط أو النقر على الختم الشمعي:
   - ينكسر الختم الشمعي مع انبعاث جزيئات ذهبية متلألئة (Golden Sparkle Burst).
   - ينفتح غطاء المظروف ثلاثي الأبعاد (3D Fold Unfold).
   - تنزلق بطاقة الدعوة الداخلية بسلاسة للأعلى.
   - تبدأ الموسيقى الهادئة تلقائياً عبر مولّد Web Audio API (أوتار قيثارة شرقية ناعمة).
   - تختفي شاشة المظروف تدريجياً لتكشف عن بطاقة الدعوة الكاملة.

## 📜 المرحلة 2: أقسام الدعوة التفاعلية (Interactive Scrollable Invitation)
1. **القسم الترحيبي والآية الكريمة:**
   - في الزاوية العلوية: الآية الكريمة: *"وَمِنْ آيَاتِهِ أَنْ خَلَقَ لَكُم مِّنْ أَنفُسِكُمْ أَزْوَاجًا لِّتَسْكُنُوا إِلَيْهَا وَجَعَلَ بَيْنَكُم مَّوَدَّةً وَرَحْمَةً"* [سورة الروم: 21].
   - نص مقوس علوي *"دَعْوَةُ زَفَاف"* يعلو اسم العريس **"ابراهيم حسام الدين"** برسم كوفي / رقعي بديع.
2. **صيغة الدعوة الرسمية:**
   - نص موزون ومرتب:
     *"يتشرف السيد سليم كير بدعوتكم لحضور زفاف ابنه ابراهيم حسام الدين، وذلك بمشيئة الله تعالى يوم الجمعة"*.
3. **كتلة التاريخ وتفاصيل المكان والبرنامج:**
   - تأطير خطي مذهب ليوم: **الـجـمـعـة**
   - تاريخ بارز: **25 ديسمبر 2026** (25 / 12 / 2026 م)
   - مكان الحفل: **قاعة الماسة - قمار** (ولاية الوادي)
   - جدول المواعيد المنظم في بطاقتين أنيقتين:
     - **العقد الشرعي:** الساعة 10:00 صباحاً
     - **مأدبة الغداء:** الساعة 10:30 صباحاً
4. **العد التنازلي الحي (Live Countdown Timer):**
   - عداد دقيق موجه نحو **25 ديسمبر 2026 الساعة 10:00:00 صباحاً**.
   - 4 أعمدة واضحة بالأرقام العنابية تفصل بينها نقطتان: (`أيام : ساعات : دقائق : ثواني`).
5. **شبكة الأزرار الدائرية التفاعلية ("اضغط للتفاعل"):**
   - 5 أزرار دائرية رفيعة الخط (`1px solid #7A1C33`) بتوزيع (3 في الصف الأول، 2 في الصف الثاني):
     1. **موقع العقد الشرعي:** نافذة تفاعلية مع رابط مباشر لخرائط Google Maps لقاعة الماسة.
     2. **موقع مأدبة الغداء:** تفاصيل مأدبة الغداء مع مسار الخريطة.
     3. **تأكيد الحضور (RSVP):** نموذج منبثق لتسجيل الاسم، حالة الحضور، عدد المرافقين، والتهنئة، مع حفظ البيانات محلياً.
     4. **إضافة للتقويم:** توليد وتنزيل ملف تقويم قياسي `.ics` متوافق مع Apple Calendar و Google Calendar و Outlook.
     5. **مشاركة الدعوة:** استخدام Web Share API الأصلي للهواتف أو نسخ الرابط للحافظة مع إشعار Toast أنيق.
6. **خاتمة الحفل وخيار إعادة فتح المظروف:**
   - عبارة الختام: *"حضوركم شرفٌ يزهو به حفلنا، ويزيد من بهجتنا وسرورنا"*.
   - زر لإعادة إغلاق المظروف وتجربة الفتح مرة أخرى.

## 🛠️ البنية التقنية (Tech Stack)
- **HTML5:** بناء دلالي RTL كامل (`dir="rtl"`, `lang="ar"`).
- **CSS3:** رسوم متحركة ثلاثية الأبعاد (3D transforms, clip-path, keyframes)، وتنسيق هاتف أولاً متجاوب (Mobile-first 480px frame).
- **Vanilla JavaScript:** بدون أي مكتبات خارجية ثقيلة، تفاعل خفيف وسريع بنسبة 100%.
- **Web Audio API:** توليد نغمات القيثارة الهادئة برمجياً دون الحاجة لملفات صوت خارجية قد تتعطل.
- **SVG Graphics:** رسومات متجهة نباتية وأيقونات مدمجة لضمان صفاء العرض على شاشات Retina دون أي روابط صور مكسورة.
